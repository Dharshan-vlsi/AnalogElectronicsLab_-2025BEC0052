AIM:
To obtain and plot the drain characteristics and transfer characteristics of an NMOS transistor using circuit simulation software.

Procedure:
1.Draw the NMOS test schematic in Virtuoso with Ves and Vos bias sources connected to the device terminals.
2. Run the DC operating-point analysis in ADE-L and print the DC operating point of the device from Results → Print → DC Operating Point. Note the region of operation (satura- tion/triode) from the printed op-point summary.
3. Plot the drain characteristics, Ip vs Vps, for the device.
4. Use Tools→ Parametric Analysis to sweep Vcs and obtain a family of Ip vs Vps curves for different values of Vos.
5. To save the DC operating-point parameters for further post-processing, create a save file from the terminal

Result:
The drain and transfer characteristics of the NMOS device were obtained, the region of operation was verified from the DC operating point.
